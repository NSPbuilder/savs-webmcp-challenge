# Devpost gallery assets

These existing 1280×720 video frames tell the same R0→R1→R2 story as the live
app and accepted demo. Use the first three if the form needs only a compact
gallery; add the fourth when the form permits it.

The paths below refer to the entrant's local production workspace. Raw audio,
video, and generated capture files are intentionally excluded from the source
repository; upload the selected PNG files directly to Devpost.

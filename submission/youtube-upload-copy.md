SAVS: Visual Proof for WebMCP Agents | WebMCP Challenge

## Description

A successful tool call is not a visual verdict.

SAVS is an agent-native visual verification workbench built for the WebMCP Challenge. The page exposes four native WebMCP tools that let an agent read an immutable visual state, create a new UI revision, audit the exact rendered result, and apply a constrained repair.

In this demo, a valid compact-layout action succeeds but creates a subtle two-CSS-pixel baseline defect. SAVS returns a fresh `BLOCK` verdict for that revision, refuses to let stale evidence approve a newer state, and returns `PASS` only after a fresh audit of the repaired revision.

The result is a shared proof surface: the agent receives structured, revision-bound evidence, while the person sees the same defect, repair, history, and verdicts.

Live demo: https://savs-webmcp-challenge.onrender.com
